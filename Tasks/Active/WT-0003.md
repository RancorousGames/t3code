## Description

Replace unreliable OpenRig/OmniHub Caffy runtime with one T3-owned persisted scheduler and T3 delivery queue. Support unthrottled wake-on-idle, periodic at 20-minute intervals, once-only, startup resume, and capacity-gated infinite wake-on-idle queued. Active Caffy prevents Windows auto-sleep while T3 runs; release when no eligible monitor remains. Existing working sessions are not interrupted; one pending wake per session, verified-delivery receipts, preserved exact conversation identity, error recovery integration. TaskBoard optional. Agents call one caffy set/stop/pause/status/list/wake interface via OMCPT; legacy aliases migrate/forward safely without duplicate schedulers. Queued mode waits for capacity and Keep T3 Busy, nonqueued modes never gate on capacity.
